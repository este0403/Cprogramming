16MB 메모리의 주소 범위: 16MB = 16×2²⁰ byte = 16,777,216byte이므로 주소는 0번지 ~ 16,777,215번지(0 ~ 16×2²⁰-1)까지 존재한다. \n
변수의 주소: 변수가 차지하고 있는 메모리 공간의 시작 번지(그 변수가 차지한 바이트들 중 가장 작은 주소값)를 말한다.

변수의 주소의 자료형: 그 변수의 자료형에 *를 붙인 형태다. 즉 int형 변수의 주소는 int형, double형 변수의 주소는 double형이다.

포인터란: 주소를 저장하기 위한 변수(주소형 변수)다. 일반 변수가 데이터(정수·실수·문자) 자체를 저장하는 것과 달리, 포인터는 다른 변수가 저장된 메모리의 주소를 저장한다.

포인터의 자료형: 포인터에 저장되는 주소가 가리키는 대상의 자료형에 *를 붙인 형태다(예: int를 가리키면 int*, char를 가리키면 char*).

주소를 int형 변수에 저장하면: 32비트 시스템에서는 주소값이 4바이트라 int(4바이트)에 담을 수 있지만, 64비트 시스템에서는 주소값이 8바이트이므로 int형 변수에는 다 담기지 못해 값이 잘리거나(overflow) 컴파일러가 경고/오류를 낸다. 따라서 주소는 int형이 아니라 반드시 알맞은 포인터 변수에 저장해야 한다.


pt가 가리키는 데이터의 자료형: double

pt에 저장될 주소의 자료형: double*

pt의 자료형: double* (pt는 double형을 가리키는 포인터)

여기서 double의 의미: 포인터 pt가 가리키게 될 대상(주소가 가리키는 메모리 공간에 저장된 값)의 자료형이 double이라는 뜻이다. *가 "포인터 변수"임을 나타내고, 앞의 자료형은 "무엇을 가리키는 포인터인지"를 나타낸다.

포인터 변수 pt가 메모리에 할당될 때 크기: 가리키는 자료형(double)과 무관하게, 시스템에 따라 32비트 시스템이면 4바이트, 64비트 시스템이면 8바이트가 할당된다(주소값 자체의 크기이기 때문).
