## 13장 포인터와 배열

### 실습과제 1 (서술형)

**1) 배열명의 의미를 설명하라.**

배열명은 배열의 **첫번째 요소의 주소**(`&배열명[0]`)를 나타내는 값이다.
단, 일반 포인터 변수와 달리 배열명은 **변수가 아니라 상수(포인터 상수)**이므로
`배열명 = 다른주소;` 처럼 값을 새로 대입할 수 없다.
배열명이 가리키는 자료형은 첫번째 요소의 자료형이며, 배열명 자체의 자료형은
"(요소 자료형)\*" 이다.

**2) 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.**

| 구분 | 배열표현 | 포인터(주소) 표현 |
|---|---|---|
| 배열요소의 값 | `a[i]` | `*(a+i)` |
| 배열요소의 주소 | `&a[i]` | `a+i` |

**3) 배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방법은?**

배열은 모든 요소가 메모리에 **연속적으로** 할당되므로, 첫번째 요소의 주소에
`i * (자료형 크기)`만큼 더하면 i번째 요소의 주소가 된다.
포인터 연산에서는 이 계산을 컴파일러가 자동으로 처리해주므로, 사람은 그냥
`a + i` 라고만 쓰면 된다 (실제로는 내부적으로 `a + i*(가리키는 자료형의 크기)`로 계산됨).

**4) 배열의 첫번째 요소의 주소만 알면 모든 원소의 값을 계산할 수 있다. 방법은?**

위 3)번 방법으로 구한 i번째 요소의 주소 `a+i`에 간접참조연산자 `*`를 적용하면
그 위치에 저장된 값을 얻을 수 있다. 즉 `*(a+i)`가 i번째 요소의 값이 된다.

**5) 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.**

- 간접참조(`*`) : 포인터가 가리키는 주소에 저장된 값을 읽거나 씀
- 정수 덧셈(`p + n`) : `p + n*(포인터가 가리키는 자료형의 크기)`
- 정수 뺄셈(`p - n`) : `p - n*(포인터가 가리키는 자료형의 크기)`
- 증가(`p++`) : `p = p + (포인터가 가리키는 자료형의 크기)`
- 감소(`p--`) : `p = p - (포인터가 가리키는 자료형의 크기)`

(포인터끼리의 곱셈, 나눗셈 등은 정의되어 있지 않음)

**6) 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?**

포인터의 주된 목적은 배열처럼 연속된 메모리 공간에서 "다음 요소로 이동"하는
것이다. 만약 포인터 덧셈을 일반 정수 덧셈처럼 그냥 바이트 단위로 1만 더하도록
정의했다면, `int`(4바이트)나 `double`(8바이트)처럼 자료형 크기가 다른 배열에서는
`p + 1`을 해도 실제 다음 요소가 아니라 요소 중간의 엉뚱한 위치를 가리키게 된다.
따라서 컴파일러가 "포인터가 가리키는 자료형의 크기"만큼 자동으로 주소를
이동시키도록 정의함으로써, `p + n`이 항상 "n번째 다음 요소의 주소"를 의미하게
만들고, 이를 통해 배열의 인덱스(`p[n]`)와 동일하게 자연스럽게 동작하도록 한 것이다.

### 실습과제 3 요약

`int a[] = {...}` 에서 `a`는 배열명(상수)이므로 `a++`처럼 값을 변경하는 연산은
불가능하며, 컴파일 오류가 발생한다. 해결하려면 배열명 대신 그 주소를 저장한
**포인터 변수**(`int* p = a;`)를 선언하여 `p++`처럼 변수를 증가시켜야 한다.
자세한 내용은 `실습과제_3.c` 주석 참고.

### 실습과제 5

교재 300페이지 문제2(문제 13-1의 두번째 문제)는 "포인터 변수 ptr에 저장된
값 자체는 변경시키지 않고, ptr을 대상으로 덧셈연산을 하여 그 결과로 반환되는
주소 값을 통해서 모든 배열요소에 접근하여 값을 2씩 증가시키는 것"이다.

이를 double형 배열 + 키보드 실수 5개 입력(입력 저장도 `ptr+i` 덧셈연산으로 처리)
으로 변형하고, 값을 2씩 증가시키는 연산을 예제11처럼 5가지 방식으로 모두
작성했다.

| 방법 | 표현 | 비고 |
|---|---|---|
| 방법1 | `a[i] += 2;` | 배열표현 |
| 방법2 | `*(a+i) += 2;` | 배열명을 이용한 주소표현 |
| 방법3 | `p[i] += 2;` | 포인터변수를 배열처럼 사용 |
| 방법4 | `*(p+i) += 2;` | 포인터를 이용한 주소표현 (문제2가 요구하는 방식, ptr 값 불변) |
| 방법5 | `*p++ += 2;` | 증감연산자 이용 (참고용, ptr 값이 실제로 이동함) |

방법1~4는 ptr(또는 a)의 값 자체가 변하지 않지만, 방법5는 `p++`에 의해 ptr이
배열의 끝을 지나가므로 사용 후 `ptr = arr;`로 다시 복구해야 한다는 점이
문제2가 굳이 "ptr 값을 변경시키지 않고 덧셈연산으로"라는 조건을 둔 이유이다.
자세한 코드는 `실습과제_5.c` 참고.
