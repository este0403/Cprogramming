## 실습과제1 (설명문제)

**C언어에서 문자를 메모리에 저장하는 방식에 대하여 설명하라 (아스키 코드 참고)**

C언어에서 문자(char)는 실제로는 1바이트 크기의 정수로 메모리에 저장된다. 각 문자는 아스키(ASCII) 코드표에 정의된 정수값으로 변환되어 저장되며, 예를 들어 `'A'`는 65, `'a'`는 97로 저장된다. 문자열은 이러한 문자(char)들을 순서대로 저장한 배열이며, 문자열 상수는 각 문자가 연속된 메모리 공간에 순서대로 저장된 후 그 뒤에 널문자가 추가되는 형태로 저장된다.

**널문자의 용도를 설명하라**

널문자(`'\0'`, 아스키코드 0)는 문자열의 끝을 표시하는 특수한 문자이다. C언어의 문자열은 길이 정보를 별도로 저장하지 않기 때문에, 문자 배열의 어디까지가 유효한 문자열인지 알기 위해 마지막에 널문자를 저장해둔다. `printf`의 `%s`나 문자열 관련 함수들은 모두 이 널문자를 만날 때까지 문자를 처리하는 방식으로 동작한다.

**메모리에 저장된 문자열의 끝을 찾는 방법을 설명하라**

문자 배열을 처음부터 순서대로 탐색하면서 각 원소가 널문자(`'\0'`)인지 검사하고, 널문자가 나오는 위치를 문자열의 끝으로 판단한다. 즉 `str[i] != '\0'` 조건이 거짓이 되는 인덱스가 문자열의 끝이 된다.

**문자열의 길이를 구하는 알고리즘을 설명하라**

인덱스 변수를 0부터 시작하여 문자 배열을 순회하면서 널문자를 만날 때까지 인덱스를 1씩 증가시킨다. 널문자를 만나는 순간까지 증가된 인덱스 값이 곧 문자열의 길이가 된다. (라이브러리 함수 `strlen`도 내부적으로 이와 동일한 방식으로 동작한다.)

```c
int getLength(char* str)
{
    int len = 0;
    while (str[len] != '\0')
        len++;
    return len;
}
```

## 실습과제3 - 대소문자 변환

- 파일 : `실습과제3.c`
- 라이브러리 함수(`toupper`, `tolower` 등)를 사용하지 않고, 아스키코드 값의 차이(`'a' - 'A'` = 32)를 직접 더하고 빼서 대문자↔소문자를 변환한다.
- 각 문자를 순회하며 `'A'`~`'Z'` 범위면 소문자로, `'a'`~`'z'` 범위면 대문자로 변환한다.

```
문자열을 입력하시오:HelloWorld
변환결과 : hELLOwORLD
```

## 실습과제4 - 사전순으로 앞에 나오는 문자열 찾기

- 파일 : `실습과제4.c`
- 소문자로만 이루어진 문자열 2개를 입력받아, 각 문자열의 첫번째 문자의 아스키코드만 비교하여 더 작은 쪽(사전에서 앞서는 쪽)을 출력한다.
- 문제 조건에 따라 라이브러리 함수(`strcmp` 등)는 사용하지 않았다.

```
문자열을 입력하시오:hello
문자열을 입력하시오:world
사전에서 앞에 나오는 문자열: hello
```

## 실습과제5 - 문자형 포인터 배열에서 사전순 최소 문자열 찾기

- 파일 : `실습과제5.c`
- 교재에 주어진 `char* fruits[] = {"apple", "blueberry", "orange", "melon"}` 배열에서, 함수(`strcmp` 등)를 사용하지 않고 각 문자열의 **첫번째 문자**만 비교하여 사전상 가장 앞에 나오는 문자열을 찾는다.
- `fruits[i][0]`으로 각 문자열의 첫 글자에 접근하며, 최소값을 갖는 인덱스(`minIdx`)를 갱신해 나간다.

```
사전에서 가장 앞에 나오는 문자열: apple
```
