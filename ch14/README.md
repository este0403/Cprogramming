## 핵심 개념 요약
- **값에 의한 호출(call by value)**: 함수 호출시 인자의 "값"이 복사되어 매개변수(지역변수)에 저장됨. 함수 안에서 매개변수를 바꿔도 호출한 쪽의 원본 변수는 전혀 바뀌지 않음.
- **주소에 의한 호출(call by address)**: 함수 호출시 인자의 "주소(&변수)"를 전달함. 매개변수는 포인터(`int*` 등)로 선언되며, `*포인터`를 통해 호출한 쪽의 원본 변수가 저장된 메모리 공간을 직접 읽고 쓸 수 있음.
- `scanf`가 `&변수`를 요구하는 이유, 배열명이 `&` 없이 그대로 주소로 취급되는 이유도 모두 같은 원리(다른 함수의 지역변수를 변경하려면 주소가 필요함)에서 비롯됨.

## 실습과제1 (서술형)

**1) 함수의 인자(argument)와 매개변수(parameter)의 차이를 설명하라.**
인자는 함수를 **호출하는 쪽**에서 넘겨주는 실제 값(또는 변수, 주소)이고, 매개변수는 함수 **정의(선언)** 쪽에서 그 값을 받기 위해 마련해 둔 변수임. 즉 인자는 "보내는 것", 매개변수는 "받는 그릇"에 해당함.

**2) 함수가 호출될 때 컴퓨터에 의해 자동으로 실행되는 2가지를 설명하라.**
- 매개변수(지역변수)를 위한 메모리 공간이 스택에 새로 할당되고, 전달된 인자의 값(또는 주소)이 그 공간에 복사되어 저장됨.
- 함수가 종료되면 그 함수를 위해 할당되었던 메모리 공간(매개변수, 지역변수 등)이 자동으로 제거(해제)됨.

**3) 값에 의한 함수 호출방식의 문제점을 설명하라.**
호출한 쪽 변수의 "값"만 매개변수로 복사되기 때문에, 함수 안에서 매개변수를 아무리 변경해도 그 변경 내용이 원래 변수(호출한 쪽)에는 전혀 반영되지 않음. 즉 함수를 통해 다른 함수(예: main)에 선언된 변수의 값을 바꾸고 싶어도 값에 의한 호출만으로는 불가능함.

**4) 주소에 의한 함수 호출방식이 필요한 경우를 설명하라.**
호출된 함수 안에서 **호출한 쪽(다른 함수)의 지역변수 값을 실제로 변경**해야 하는 경우 반드시 필요함. 예를 들어 두 변수의 값을 교환하는 `swap` 함수나, 값을 증가/배가시켜서 원본 변수에 반영해야 하는 함수, 또는 `scanf`처럼 입력받은 값을 호출한 쪽 변수에 저장해야 하는 경우가 대표적임. 이때는 변수의 값 대신 변수의 **주소**를 전달하고, 함수 내부에서는 포인터를 통해 그 주소가 가리키는 메모리 공간을 직접 수정함.

## 실습과제2 — `실습과제2.c`
값에 의한 호출로 작성된 `add2` 함수는 매개변수만 바뀌고 main의 `number`는 바뀌지 않는 문제가 있었음. 매개변수를 포인터(`int*`)로 바꾸어 주소에 의한 호출로 수정 → `number`가 실제로 2만큼 증가함.
```
정수를 입력하세요:15
2만큼 증가한 값:17
```

## 실습과제3 — `실습과제3.c`
주소를 넘기지 않고, 값에 의한 호출을 그대로 사용하되 함수가 증가된 값을 **리턴**하고 main에서 그 리턴값을 `number`에 재대입하는 방식으로 구현함.
```
정수를 입력하세요:15
2만큼 증가한 값:17
```

## 실습과제4 — `실습과제4.c`
`swap` 함수를 참고하여 세 정수 x, y, z의 값을 `x<-y, y<-z, z<-x` 순서로 회전시키는 함수를 작성함. 세 변수 모두 다른 함수(swap)에서 실제로 바뀌어야 하므로 반드시 세 변수의 주소(`&x, &y, &z`)를 전달하는 주소에 의한 호출을 사용함.
```
정수x를 입력 하시오:10
정수y를 입력 하시오:20
정수z를 입력 하시오:30
swap함수 호출 전 x=10, y=20, z=30
swap함수 호출 후 x=20, y=30, z=10
```

## 실습과제5 — `실습과제5.c`
> 참고: 교재 320페이지 문제1번의 원본 지문은 PDF 자료에 포함되어 있지 않아 확인하지 못했습니다. 이 장이 "값/주소에 의한 호출 비교"를 다루고 있고, 문제에서 "2가지 방식의 차이를 설명하고 원하는 결과는 어느 것인가?"라고 요구한 점에 근거해, num 변수를 100배로 만드는 함수를 (1)값에 의한 호출, (2)주소에 의한 호출 두 가지로 각각 작성하여 비교하는 문제로 해석해 구현했습니다. 실제 교재 지문과 다르면 말씀해 주세요.

- **값에 의한 호출**: `num`의 "값"만 복사되어 함수 내부에서만 100배가 됨 → main의 `num`은 그대로임.
- **주소에 의한 호출**: `num`의 "주소"를 전달받아 포인터로 원본을 직접 수정 → main의 `num`이 실제로 100배가 됨.
- 우리가 원하는 결과(실제로 값이 100배로 바뀌는 것)를 얻으려면 반드시 **주소에 의한 호출**을 사용해야 함.
```
정수를 입력하시오:3

[값에 의한 호출]
호출 전 num=3
호출 후 num=3 (변경되지 않음)

[주소에 의한 호출]
호출 전 num=3
호출 후 num=300 (100배로 변경됨)
```
