## 실습과제1

변수가 아래와 같이 메모리에 할당되었다고 할 때 (num: 100번지, ptr: 300번지, dptr: 500번지)

```c
double num = 6.28;
double* ptr = &num;
double** dptr = &ptr;
```

| 수식 | 결과값 | 결과값의 자료형 |
|---|---|---|
| `ptr` | 100 | `double*` |
| `dptr` | 300 | `double**` |
| `&ptr` | 300 | `double**` |
| `&dptr` | 500 | `double***` |
| `*ptr` | 6.28 | `double` |
| `*dptr` | 100 | `double*` |
| `**dptr` | 6.28 | `double` |

**설명**
- `ptr`은 `num`의 주소(100)를 저장하고 있으므로 값은 100, 자료형은 `double*`이다.
- `dptr`은 `ptr`의 주소(300)를 저장하고 있으므로 값은 300, 자료형은 `double**`이다. `&ptr`도 같은 값이다.
- `&dptr`은 `dptr` 변수 자체의 주소(500)이며, `double**`의 주소이므로 자료형은 `double***`이다.
- `*ptr`은 `ptr`이 가리키는 곳(100번지)의 값인 6.28(`double`)이다.
- `*dptr`은 `dptr`이 가리키는 곳(300번지, 즉 `ptr`)의 값인 100(`double*`)이다.
- `**dptr`은 `*dptr`(=100)이 가리키는 곳의 값이므로 `num`의 값 6.28(`double`)이다.

## 실습과제4 (교재 368쪽 문제 17-1)

배열에서 최댓값과 최솟값을 찾아, **값이 아니라 그 원소의 주소**를 `main`의 포인터 변수 `maxPtr`, `minPtr`에 저장해 주는 `MaxAndMin` 함수를 만든다. (`실습과제4.c`)
<img width="1096" height="171" alt="image" src="https://github.com/user-attachments/assets/af2fce34-fe80-4092-9c9f-f01f6cf2e93c" />


### 왜 이중 포인터가 필요한가?

- `main`의 `maxPtr`, `minPtr`은 **포인터 변수**이고, 함수가 이 변수의 **값(주소)을 바꿔야** 한다.
- 값에 의한 호출로 `int*`를 넘기면 복사본만 바뀌고 `main`의 포인터는 그대로이다. (예제3의 방식)
- 그래서 포인터 변수의 주소(`&maxPtr`, 자료형 `int**`)를 넘기고, 함수에서 `*mxPtr = max;`로 원본 포인터를 바꾼다. (예제4의 방식)

### 메모리 그림

입력이 `30 10 50 20 40`일 때 (주소는 설명을 위해 임의로 정한 값이다)

**함수 호출 직후 (`MaxAndMin` 진입 시점)**

```
main 함수                                      MaxAndMin 함수
┌──────────────────────────┐                  ┌───────────────────────────┐
│ 주소 0x1000  arr[0]  30  │ ◄────────────────│ arr    = 0x1000   (int*)  │
│ 주소 0x1004  arr[1]  10  │                  │ size   = 5                │
│ 주소 0x1008  arr[2]  50  │                  │ mxPtr  = 0x2000  (int**)  │──┐
│ 주소 0x100C  arr[3]  20  │                  │ mnPtr  = 0x2008  (int**)  │──┼─┐
│ 주소 0x1010  arr[4]  40  │                  │ max, min, i               │  │ │
├──────────────────────────┤                  └───────────────────────────┘  │ │
│ 주소 0x2000  maxPtr  ??? │ ◄───────────────────────────────────────────────┘ │
│ 주소 0x2008  minPtr  ??? │ ◄─────────────────────────────────────────────────┘
└──────────────────────────┘
```

**탐색 과정** (`max`, `min`은 함수의 지역 포인터)

| i | arr[i] | `*max`와 비교 | `*min`과 비교 | max | min |
|---|---|---|---|---|---|
| (초기) | - | - | - | 0x1000 (30) | 0x1000 (30) |
| 1 | 10 | 30 < 10 거짓 | 30 > 10 참 | 0x1000 (30) | 0x1004 (10) |
| 2 | 50 | 30 < 50 참 | 10 > 50 거짓 | 0x1008 (50) | 0x1004 (10) |
| 3 | 20 | 50 < 20 거짓 | 10 > 20 거짓 | 0x1008 (50) | 0x1004 (10) |
| 4 | 40 | 50 < 40 거짓 | 10 > 40 거짓 | 0x1008 (50) | 0x1004 (10) |

**함수 종료 직전 (`*mxPtr = max;`, `*mnPtr = min;` 실행 후)**

```
main 함수
┌──────────────────────────┐
│ 0x1000  arr[0]  30       │
│ 0x1004  arr[1]  10  ◄────┼──────────────┐
│ 0x1008  arr[2]  50  ◄────┼───────┐      │
│ 0x100C  arr[3]  20       │       │      │
│ 0x1010  arr[4]  40       │       │      │
├──────────────────────────┤       │      │
│ 0x2000  maxPtr  0x1008 ──┼───────┘      │
│ 0x2008  minPtr  0x1004 ──┼──────────────┘
└──────────────────────────┘
→ *maxPtr = 50, *minPtr = 10  (출력: 최대: 50, 최소: 10)
```

### 소스코드 라인별 설명

**함수선언 / main 함수**

| 코드 | 설명 |
|---|---|
| `#define _CRT_SECURE_NO_WARNINGS`<br>`#pragma warning(disable:6031)` | Visual Studio에서 `scanf` 사용 시 나오는 보안 경고와 반환값 무시 경고(6031)를 끈다. |
| `#include <stdio.h>` | `printf`, `scanf`를 쓰기 위한 표준 입출력 헤더 |
| `void MaxAndMin(int* arr, int size, int** mxPtr, int** mnPtr);` | 함수선언. 배열의 시작 주소(`int*`), 원소 개수, 그리고 최댓값/최솟값 원소의 주소를 저장할 포인터 변수의 주소(`int**` 2개)를 받는다. 반환값은 없고 결과는 이중 포인터를 통해 전달한다. |
| `int main(void)` / `{` | 프로그램 시작 |
| `int* maxPtr;` | 최댓값 원소를 가리킬 포인터 변수(8바이트). 아직 값이 없고 함수가 채워 준다. |
| `int* minPtr;` | 최솟값 원소를 가리킬 포인터 변수(8바이트). 함수가 채워 준다. |
| `int arr[5];` | 정수 5개(20바이트)를 저장할 배열. 메모리에 연속으로 할당된다. |
| `int i;` | 반복문 제어 변수 |
| `for (i = 0; i < 5; i++)` | 배열의 5개 원소를 차례로 입력받기 위한 반복문 |
| `printf("정수 입력 %d: ", i + 1);` | 몇 번째 입력인지 1부터 번호를 붙여 안내 메시지를 출력 |
| `scanf("%d", &arr[i]);` | `&arr[i]`(i번째 원소의 주소)에 입력값을 저장 |
| `MaxAndMin(arr, sizeof(arr) / sizeof(int), &maxPtr, &minPtr);` | `arr`는 배열 시작 주소(`int*`), `sizeof(arr)/sizeof(int)`는 20/4=5(원소 개수). `&maxPtr`, `&minPtr`은 포인터 변수의 주소(`int**`)로, 함수가 `main`의 포인터 변수를 직접 바꿀 수 있게 한다. |
| `printf("최대: %d, 최소: %d \n", *maxPtr, *minPtr);` | 함수가 채워 준 `maxPtr`, `minPtr`이 최댓값/최솟값 원소를 가리키므로 `*`로 값을 읽어 출력 |
| `return 0;` / `}` | 프로그램 정상 종료 |

**MaxAndMin 함수**

| 코드 | 설명 |
|---|---|
| `void MaxAndMin(int* arr, int size, int** mxPtr, int** mnPtr)` | 함수정의. `arr`에는 배열 시작 주소(0x1000), `mxPtr`에는 `&maxPtr`(0x2000), `mnPtr`에는 `&minPtr`(0x2008)가 복사되어 들어온다. |
| `int* max, * min;` | 지금까지 찾은 최댓값, 최솟값 원소의 주소를 저장하는 지역 포인터 변수 2개 |
| `int i;` | 반복문 제어 변수 |
| `max = min = &arr[0];` | 처음에는 첫 번째 원소의 주소를 `max`와 `min` 둘 다에 저장한다. (첫 원소를 최댓값이자 최솟값으로 가정) |
| `for (i = 1; i < size; i++)` | 두 번째 원소부터 마지막 원소까지 차례로 비교한다. (교재 답안은 `i = 0`부터 시작하는데, `arr[0]`을 자기 자신과 비교할 필요가 없어서 1부터 시작했다. 결과는 같다.) |
| `if (*max < arr[i])` | `max`가 가리키는 값(현재 최댓값)보다 `arr[i]`가 더 큰지 비교 |
| `max = &arr[i];` | 더 큰 값을 찾았으므로 `max`가 `arr[i]`를 가리키도록 주소를 바꾼다. (값이 아니라 **주소**를 저장하는 것에 주의) |
| `if (*min > arr[i])` | `min`이 가리키는 값(현재 최솟값)보다 `arr[i]`가 더 작은지 비교 |
| `min = &arr[i];` | 더 작은 값을 찾았으므로 `min`이 `arr[i]`를 가리키도록 주소를 바꾼다. |
| `*mxPtr = max;` | `mxPtr`은 `maxPtr`의 주소이므로 `*mxPtr`은 `main`의 `maxPtr` 자체이다. 여기에 최댓값 원소의 주소를 저장한다. |
| `*mnPtr = min;` | 마찬가지로 `main`의 `minPtr`에 최솟값 원소의 주소를 저장한다. 함수가 끝나도 `maxPtr`, `minPtr`은 `main`의 변수이므로 값이 유지된다. |
| `}` | 함수 종료. `max`, `min`, `i` 등 지역 변수는 사라지지만 `main`의 포인터는 이미 값이 바뀌어 있다. |

### 정리

- `int**` 매개변수 = "포인터 변수의 주소"를 받는 것 → 함수 안에서 **포인터 변수 자체**를 바꿀 수 있다.
- `*mxPtr = max;`에서 `*mxPtr`은 `int*` 형(= `maxPtr`), `**mxPtr`이면 `int` 형(= 최댓값 자체)이다.
- 반환값은 1개뿐이지만, 이중 포인터를 이용하면 한 함수에서 여러 개의 결과(최댓값 위치, 최솟값 위치)를 돌려줄 수 있다.
