## 실습과제1

### 1. 표준 입출력 스트림을 접근하는 방법

스트림은 소프트웨어적으로 하나의 변수(데이터)이므로 이를 나타내는 자료형이 필요한데, 그것이 `FILE`(구조체)이다. 표준 스트림 `stdin`, `stdout`, `stderr`는 각 스트림의 **주소로 정의된 주소형 상수**이므로 자료형이 `FILE*`이다.

문자·문자열 전용 입출력 함수에 이 **주소를 인자로 전달**해서 스트림에 접근한다.

```c
fputc(ch, stdout);          // 표준 출력 스트림(모니터)에 문자 출력
ch = fgetc(stdin);          // 표준 입력 스트림(키보드)에서 문자 입력
fputs(str, stdout);         // 표준 출력 스트림에 문자열 출력
fgets(str, sizeof(str), stdin);  // 표준 입력 스트림에서 문자열 입력
```

`putchar`, `getchar`, `puts`, `gets`는 스트림 인자를 생략한 형태로, 각각 `stdout`, `stdin`을 사용하는 것과 같다. (`putchar(c)` = `fputc(c, stdout)`, `getchar()` = `fgetc(stdin)`)

### 2. 공백을 포함한 문자열을 입력받을 때 사용 가능한 함수

**`gets`와 `fgets`**를 사용한다. 두 함수는 엔터키가 입력되기 전까지 공백을 포함한 문자열을 저장한다.

`scanf("%s", ...)`는 공백을 만나면 입력을 끝내므로 `"I am a boy."`를 입력해도 `"I"`만 저장된다.

### 3. `gets` 함수 사용 시 가장 큰 문제점

**입력 문자열의 길이가 배열의 크기보다 큰지 검사하지 않는다는 점**이다. 배열 크기를 넘는 문자열이 입력되면 할당받지 않은 메모리 영역에 값이 써져서 실행 오류가 발생한다. (예제5에서 `char str[12]`에 `"I am a boy, you are a girl."`을 입력했을 때 `Stack around the variable 'str' was corrupted` 오류가 발생함) 이런 위험 때문에 `gets`는 사용하지 말고 크기를 지정할 수 있는 `fgets`를 쓰는 것이 안전하다.

### 4. `fgets` 함수 사용 시 문제점

1. **엔터키(`'\n'`)가 문자열에 저장된다.** `gets`는 엔터키를 널문자로 바꿔 저장하지만, `fgets`는 엔터키를 읽어서 배열에 그대로 저장하고 그 뒤에 널문자를 넣는다. 그래서 `printf("%s", str)`로 출력하면 줄바꿈이 한 번 더 발생하고, 문자열을 비교하거나 길이를 셀 때도 엔터키가 포함되어 문제가 생긴다. → 배열에서 `'\n'`을 찾아 `'\0'`으로 바꾸어 해결한다. (실습과제4)
2. **입력이 지정한 크기보다 길면 남은 글자가 입력 버퍼에 남는다.** `fgets`는 널문자를 포함하여 `n`개까지만 저장하므로 `(n-1)`개를 읽고 나머지(엔터키 포함)는 버퍼에 남아 다음 입력 함수에 영향을 준다. (예제7에서 `"950915-1122345"`를 입력하면 이름 입력에 `-1122345`가 들어감) → 버퍼에 남은 문자를 `'\n'`이 나올 때까지 `getchar()`로 읽어서 비워준다. (예제8의 `ClearLineFromReadBuffer`)

### 5. 널문자(`'\0'`)와 널포인터(`NULL`)의 용도

| 구분 | 널문자 `'\0'` | 널포인터 `NULL` |
|---|---|---|
| 정체 | 값이 0인 **문자** 상수 (아스키코드 0) | `((void*)0)`, 아무것도 가리키지 않는 **주소** 상수 |
| 용도 | **문자열의 끝**을 표시한다. `printf`, `puts` 같은 함수는 널문자를 만날 때까지를 하나의 문자열로 처리한다. | 포인터가 **유효한 대상을 가리키고 있지 않음**을 나타낸다. |
| 예 | `char str[10] = "hello";` 에서 `str[5]`가 `'\0'` | `gets`, `fgets`가 오류가 나거나 파일 끝에 도달했을 때 반환하는 값. 포인터 변수의 초기화 `char* p = NULL;` |

두 값 모두 0이지만 자료형이 다르다. 널문자는 문자열 안에서 끝을 알리는 데이터이고, 널포인터는 포인터 변수에 저장되는 주소 값이다.

## 실습과제2~5 요약

- **실습과제2**: `getchar`로 문자를 입력받고 `putchar`로 출력한다. 입력을 완성한 엔터키가 버퍼에 남으므로 `'\n'`까지 읽어서 버린다(안 그러면 다음 `getchar`가 엔터키를 입력받음). `getchar`의 반환값은 `EOF(-1)`을 구분해야 하므로 `int`형 변수에 저장한다. 문자 입출력 전용함수만 쓰라는 조건에 맞춰 안내 문구도 `putchar`로 한 글자씩 출력하는 함수를 만들어 사용했다.
- **실습과제3**: `fgets`로 공백이 포함된 주소(`군산시 대학로 558`)까지 입력받는다. 한글은 한 글자가 2바이트이므로 배열 크기를 넉넉하게 잡았고, 엔터키를 널문자로 바꾼 뒤 `fputs`/`puts`로 출력한다.
- **실습과제4**: `fgets` 뒤에 배열을 처음부터 훑으며 `'\n'`을 찾아 `'\0'`으로 바꾼다. 문자열이 거기서 끝나므로 `printf("%s")`로 출력해도 줄바꿈이 생기지 않는다.
- **실습과제5**: 공백이 아닌 문자가 새로 시작될 때마다 단어 수를 1 증가시킨다. 단순히 공백 개수 + 1로 세면 공백이 연속되거나 앞뒤에 있을 때 틀리므로 `inWord` 변수로 단어 안/밖 상태를 구분했다.
