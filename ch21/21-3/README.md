# 21장 문자와 문자열 관련 함수 - 실습과제

작성자: 2600152 이준영 / 날짜: 2026년 10월 29일

## 핵심 개념 정리

| 함수 | 헤더 | 설명 |
|------|------|------|
| `strlen(str)` | string.h | 널문자를 제외한 문자열 길이 반환 |
| `strcpy(dest, src)` | string.h | src를 널문자 포함하여 dest에 복사 (dest 범위 초과 위험) |
| `strncpy(dest, src, n)` | string.h | 최대 n개만 복사. 널문자가 n개 안에 없으면 복사되지 않으므로 `dest[n-1] = '\0'`을 직접 넣어야 함 |
| `strcat(dest, src)` | string.h | src를 dest 뒤에 연결 (dest에 충분한 공간 필요) |
| `strncat(dest, src, n)` | string.h | 최대 n개를 연결하고 널문자를 자동 추가 |
| `strcmp(s1, s2)` | string.h | 같으면 0, s1이 크면 양수, s2가 크면 음수 (아스키코드 기준) |
| `atoi / atol / atof` | stdlib.h | 문자열 -> int / long / double |
| `sscanf / sprintf` | stdio.h | 문자열 -> 수치 / 수치 -> 문자열 |

## 참고 사항
- 모든 파일은 `gcc -w`로 컴파일하여 위 입력값으로 실행 결과를 확인했습니다.
- `my_strcpy`, `my_strcat`은 반환형을 `char*`로 하여 표준 함수처럼 dest의 주소를 반환하도록 작성했습니다.
- 실습과제2에서는 슬라이드에 정의가 없는 `RemoveBSN`도 `my_strlen`을 사용하도록 함께 작성했습니다.
