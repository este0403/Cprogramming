## 실습과제1

### 1) 스트림과 버퍼의 역할

- **스트림(stream)**: 프로그램과 입출력장치 사이에서 데이터가 이동하는 소프트웨어적 경로(다리)이다. 물이 한 방향으로 흐르듯 한 방향으로만 데이터가 이동하므로 입력 스트림, 출력 스트림이 따로 있다. 표준 입력(stdin), 표준 출력(stdout), 표준 에러(stderr) 스트림은 프로그램 시작 시 운영체제가 자동으로 만들고 종료 시 없앤다.
- **버퍼(buffer)**: 입출력장치와 프로그램 사이에서 데이터를 임시로 저장하는 메모리 공간이다. 스트림 내부에 포함되어 있고 운영체제가 관리한다.

### 2) 버퍼 사용의 장점과 단점

**장점**
- 데이터를 모아서 한 번에 전송하므로 하나씩 보내는 것보다 처리 시간이 짧고 효율적이다. (창고 물건을 손수레로 한 번에 나르는 것과 같다.)
- 속도가 다른 장치(느린 입출력장치와 빠른 CPU) 사이에서 데이터 손실을 막아준다.
- 엔터키가 입력되기 전에는 버퍼 안의 데이터를 수정(백스페이스 등)할 수 있다.

**단점**
- 입력 버퍼에 이전 입력의 찌꺼기(엔터키 `'\n'` 등)가 남아 있으면 다음 `scanf("%c")`가 입력을 기다리지 않고 그 문자를 읽어 버려 의도와 다르게 동작한다. (예제1, 실습과제3, 4)
- 출력 버퍼는 특정 조건(버퍼가 가득 참, 개행 등)이 될 때까지 화면에 바로 나타나지 않을 수 있어, 출력 시점이 즉시가 아니다.
- 버퍼를 위한 메모리 공간이 추가로 필요하다.

### 3) 입력 버퍼에 데이터가 이미 있을 때 scanf를 호출하면?

사용자의 키보드 입력을 기다리지 않고 **버퍼에 있는 문자를 바로 읽고 리턴**한다. 입력 버퍼가 비어 있을 때만 키보드 입력을 기다린다.

### 4) 운영체제가 출력 버퍼의 데이터를 모니터로 출력하는 경우

- 출력 버퍼가 가득 찼을 때
- 문장 입력이 완료되었을 때 (개행 문자 `'\n'`이 출력될 때)
- 그 외 프로그램 종료, `fflush(stdout)` 호출 등

전송 후에는 출력 버퍼가 비워진다.

### 5) scanf / printf 실행 시 함수와 운영체제의 역할 분담

| | 함수(프로그램)의 역할 | 운영체제의 역할 |
|---|---|---|
| `printf` | 출력할 데이터를 **출력 버퍼에 넣고** 바로 리턴 (모니터에 직접 출력하지 않음) | 특정 조건이 되면 출력 버퍼의 데이터를 **모니터로 전송**하고 버퍼를 비움 |
| `scanf` | **입력 버퍼에서** 데이터를 읽어 변수에 저장하고 버퍼에서 삭제 (키보드에서 직접 읽지 않음). 버퍼가 비어 있으면 OS 함수를 호출하고 대기 | 키를 누를 때마다 한 문자씩 **입력 버퍼로 전송**하고, 엔터키가 입력되면 대기 중인 `scanf`로 복귀시킴 |

## 실습과제3

### 위쪽 실행결과처럼 나오는 이유

<img width="1103" height="149" alt="image" src="https://github.com/user-attachments/assets/bc6ea5b7-0fc8-4f78-8013-75dded0e62b4" />


1. `scanf("%s", name)`은 "홍길동"만 읽어 `name`에 저장하고 버퍼에서 제거한다. 입력완료문자인 엔터키 `'\n'`은 **버퍼에 남는다**.
2. 다음 `scanf("%c", &blood_type)`가 실행될 때 입력 버퍼가 비어 있지 않으므로 사용자 입력을 기다리지 않고 남아있던 `'\n'`을 바로 `blood_type`에 저장한다.
3. 그래서 혈액형을 입력할 기회가 없이 넘어가고, `blood_type`의 값 `'\n'`이 출력되어 "혈액형:" 뒤에 빈 줄이 나온다.

```
① scanf("%s", name); 직전 입력 버퍼 (오른쪽부터 읽음)
   [ \n ][ 동 ][ 길 ][ 홍 ]  ← 홍길동<엔터>

② scanf("%s", name); 실행 후 → name = "홍길동"
   [    ][    ][    ][ \n ]  ← '\n'이 남음

③ scanf("%c", &blood_type); → 대기 없이 '\n'을 읽음
   blood_type = '\n', 버퍼는 비워짐
```

### 수정 방법

`scanf("%c", &blood_type);` → `scanf(" %c", &blood_type);`  
`%c` 앞의 공백은 whitespace(space, enter, tab)를 읽어서 버리라는 의미이므로 남아있던 `'\n'`을 버리고, `'A'`가 입력될 때까지 기다린다.

```
① scanf(" %c", &blood_type); 직전 버퍼
   [    ][    ][    ][ \n ]

② 공백 처리: '\n'(whitespace)을 읽어서 버리고, 버퍼가 비었으므로 입력 대기
   → "A<엔터>" 입력
   [    ][    ][ \n ][ A ]

③ 'A'를 blood_type에 저장, 버퍼에는 '\n' 남음
   blood_type = 'A'
   [    ][    ][    ][ \n ]
```

(`scanf("%c")` 전에 `getchar();`로 `'\n'`을 비우는 방법도 있다.)

## 실습과제4

```c
for (i = 0; i < 5; i++)
{
    printf("문자 입력:");
    scanf("%c", &ch);
    printf("문자: %c\n", ch);
}
```

### 반복 단계별 버퍼 상태

입력 버퍼는 앞쪽(먼저 읽는 쪽)을 왼쪽에 적었다.

| 반복 | scanf 실행 전 버퍼 | 동작 | ch | scanf 실행 후 버퍼 |
|---|---|---|---|---|
| i=0 | (비어 있음) | 버퍼가 비어 있으므로 **입력 대기** → `abcde<엔터>` 입력 → 버퍼에 `a b c d e \n` 저장 | `'a'` | `b c d e \n` |
| i=1 | `b c d e \n` | 버퍼에 문자가 있으므로 **대기 없이** 바로 읽음 | `'b'` | `c d e \n` |
| i=2 | `c d e \n` | 대기 없이 읽음 | `'c'` | `d e \n` |
| i=3 | `d e \n` | 대기 없이 읽음 | `'d'` | `e \n` |
| i=4 | `e \n` | 대기 없이 읽음 | `'e'` | `\n` |

```
i=0:  입력 대기 → abcde<엔터>
      [ \n ][ e ][ d ][ c ][ b ][ a ]  → 'a'를 ch에 저장
i=1:  [ \n ][ e ][ d ][ c ][ b ]        → 'b'
i=2:  [ \n ][ e ][ d ][ c ]             → 'c'
i=3:  [ \n ][ e ][ d ]                  → 'd'
i=4:  [ \n ][ e ]                       → 'e'
종료: [ \n ]                            ← 엔터키가 버퍼에 남음
```

### 설명

- 첫 번째 반복에서만 사용자 입력을 기다리고, 입력한 `abcde<엔터>` 6글자(`a b c d e \n`)가 모두 입력 버퍼에 들어간다. `scanf("%c")`는 한 글자만 가져가므로 `'a'`만 읽힌다.
- 두 번째 반복부터는 버퍼에 이미 문자가 남아있어 키보드 입력을 기다리지 않고 `b`, `c`, `d`, `e`를 차례로 바로 읽는다. 그래서 "문자 입력:" 바로 뒤에 "문자: b"가 이어서 출력된다.
- 5번 반복이 끝난 뒤에도 엔터키 `'\n'`은 버퍼에 남아 있다.

## 실습과제5

`scanf("%s", str)`은 공백 앞까지만 읽으므로 "Hello world"에서 "Hello"만 저장된다. 이를 `scanf("%c", &ch)`로 한 글자씩 읽어 엔터키(`'\n'`)가 나올 때까지 배열에 복사하고, 마지막에 널문자(`'\0'`)를 대입하는 방식으로 수정했다.

- 공백도 하나의 문자이므로 그대로 배열에 저장되어 "Hello world" 전체가 입력된다.
- 배열 크기가 20이므로 `i < 19` 조건으로 최대 19글자까지만 저장하고 마지막 칸은 널문자 자리로 남겨 배열을 넘치지 않게 했다.

```
입력 버퍼:  H e l l o ␣ w o r l d \n
str 배열:   H e l l o ␣ w o r l d \0   (i=11에서 '\n'을 만나 종료 후 str[11]='\0')
```
