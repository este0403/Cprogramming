# 22장 구조체 — 실습과제

작성자: 2600152 이준영 / 날짜: 2026년 11월 3일

## 핵심 개념 요약

| 항목 | 내용 |
|---|---|
| 구조체 | 서로 다른 자료형(char, int, double 등)의 데이터를 묶어 만든 사용자 정의 자료형 |
| 정의 | `struct 구조체명 { 멤버변수들 };` — 중괄호 뒤 세미콜론 필수, 보통 main 앞에 정의 |
| 변수 선언 | `struct 구조체명 변수명;` — 이때 멤버들이 연속된 메모리에 선언 순서대로 할당됨 |
| 초기화 | 배열처럼 중괄호로 나열: `struct student s1 = { 24, "Kim", 4.3 };` |
| 멤버 접근 | 멤버 연산자 `.` 사용: `구조체변수명.멤버변수명` |
| 문자열 멤버 | `s1.name = "Kim";`은 오류 → `strcpy(s1.name, "Kim");` 사용 |

## 실습과제1 (서술형)

**1. 구조체가 필요한 이유**
학번(int), 이름(char 배열), 학점(double)처럼 한 학생에 대한 서로 다른 종류의 데이터를 변수로 따로따로 선언하면 한 사람의 데이터로 묶어서 다루기 힘들고, 학생 수가 늘수록 변수가 폭발적으로 많아져 관리가 불편해진다. 구조체로 관련 데이터를 하나로 묶으면 사용과 관리가 매우 편리해진다.

**2. 배열과의 공통점과 차이점**

| | 배열 | 구조체 |
|---|---|---|
| 공통점 | 여러 데이터를 하나로 묶어 다룸, 연속된 메모리 공간에 할당, 중괄호로 순서대로 나열하여 초기화 | (동일) |
| 원소 자료형 | 모두 같아야 함 | 달라도 됨 |
| 원소 구분 | `배열명[인덱스]` | `구조체변수.멤버변수명` |
| 인자 전달 | 주소에 의한 호출 | 주소에 의한 호출 선호 |

**3. 기본자료형과 구조체의 차이**
기본자료형(char, int, double 등)은 C언어가 미리 제공하는 자료형이고 값 하나를 저장한다. 구조체는 기본자료형 여러 개를 모아 프로그래머가 새로 정의하는 사용자 정의 자료형으로, 사용하려면 먼저 정의를 해야 한다.

**4. 구조체 정의와 구조체 변수 선언의 의미**

| | 구조체 정의 | 구조체 변수 선언 |
|---|---|---|
| 형태 | `struct student { ... };` | `struct student s1;` |
| 의미 | 새로운 자료형(멤버 구성)을 정의하는 일 | 그 자료형으로 변수를 만드는 일 |
| 메모리 | 할당되지 않음 (설계도 역할) | 멤버변수들이 메모리에 할당됨 (예: student s1 → 22바이트라고 슬라이드에 표기) |
