# 22장 구조체 실습과제 (2026년 11월 5일)

작성자: 2600152 이준영

## 핵심 개념 정리

| 개념 | 설명 | 예 |
|---|---|---|
| 구조체 배열 | 구조체 변수를 여러 개 모아 놓은 것. 선언·참조는 일반 배열과 같다. | `struct student list[3];` / `list[0].number = 27;` |
| 구조체 배열 초기화 | 2차원 배열 초기화와 비슷하게 중괄호를 중첩한다. | `{ {25,"Mun",3.92}, {24,"Kim",4.3} }` |
| 구조체 포인터 | 구조체 변수의 주소를 저장하는 변수 | `struct student* p = &s;` |
| 구조체 변수의 주소 | 첫 번째 멤버의 주소와 같다. (`&s == &s.number`) | 예제3 출력 |
| `->` 연산자 | 구조체 포인터로 멤버를 참조한다. `p->number`는 `(*p).number`와 같다. | `p->name` |
| 중첩 구조체 | 구조체 멤버에 다른 구조체를 둘 수 있다. | `r.p1.x` |

## 실습과제별 설명

| 과제 | 파일 | 핵심 아이디어 |
|---|---|---|
| 1 | `실습과제1.c` | 구조체 배열 + 점수의 최대값 구하기 알고리즘 |
| 2 | `실습과제2.c` | 구조체 배열 + `strcmp`로 이름의 최소값(사전순 최초) 구하기 |
| 3 | `실습과제3.c` | 과제2를 구조체 포인터(`p + i`, `->`)로 바꿔 구현 |
| 4 | `실습과제4.c` | `point`, `triangle` 구조체 + 세 변 길이의 제곱으로 피타고라스 정리 판별 |
| 5 | (미작성) | 교재 463쪽 문제 22-2 변형 — 교재 사진 필요 |

## 참고

- 과제4는 제곱근을 쓰지 않고 거리의 제곱끼리 비교해서 `double` 오차를 피했고, 세 점이 일직선인 경우(길이 0인 변)는 직각삼각형이 아니도록 처리했다.
- 과제3의 `(p + i)->name`은 `list[i].name`과 같은 의미다.
- 모든 파일은 `gcc -w`로 컴파일하고, 슬라이드의 예시 입력으로 실행 결과를 확인했다.
