## 핵심 개념 정리

- **typedef**: 기존 자료형에 새 이름을 붙임. `typedef struct { ... } Point;`처럼 구조체 이름을 생략하면 `Point a, b;`로 바로 선언 가능
- **구조체 전달**: 값에 의한 호출(복사본 전달, 원본 불변) / 주소에 의한 호출(`->`로 원본 변경, 복사 비용 절약)
- **구조체 반환**: 반환값이 2개 이상일 때 구조체로 묶어서 한 번에 리턴 가능
- **구조체 변수의 연산**: 대입(`=`), 주소(`&`), `sizeof`만 가능. `==`, `+` 등은 불가능해서 멤버별로 비교·계산하거나 함수로 정의
- **sizeof(구조체)**: 멤버 크기의 합이 아님 (정렬/패딩 때문). 예제7의 `char + int + double`은 1+4+8=13이 아니라 16바이트

## 실습과제4 참고

슬라이드의 `swap_struct(pos1, pos2)`처럼 값으로 넘기면 함수 안의 복사본만 바뀌어 main의 값은 그대로다. 그래서 `swap_struct(&pos1, &pos2)`로 주소를 전달하고, 함수 안에서 `temp = *p1; *p1 = *p2; *p2 = temp;`로 구조체 전체를 대입해 교환했다.

## 실습과제5 (교재 484쪽 문제 23-1)

`Point pos1={2, 4}; Point pos2={5, 7};`일 때 `SwapPoint`를 호출하면 pos1은 {5, 7}, pos2는 {2, 4}가 되어야 한다. 값에 의한 호출은 복사본만 바뀌므로 두 변수의 주소를 전달하는 `SwapPoint(&pos1, &pos2)` 방식으로 구현했고, 함수 안에서 `temp = *p1; *p1 = *p2; *p2 = temp;`로 구조체 전체를 대입해 교환했다.
