## 핵심 개념 정리

- **파일 입출력 순서**: `fopen`(스트림 생성) → `fgetc`/`fputc` 등으로 입출력 → `fclose`(스트림 소멸)
- **개방 모드**: `rt`(텍스트 읽기), `wt`(텍스트 쓰기, 파일이 있으면 내용을 지움), `rb`/`wb`(바이너리). `t`/`b`를 생략하면 텍스트 모드
- **오류 처리**: `fopen`은 실패 시 `NULL`을 반환하므로 반드시 검사한다. (`rt`에서 파일이 없으면 실패)
- **EOF 처리**: `fgetc`는 파일 끝에서 `EOF(-1)`를 반환하므로 반환값을 `char`가 아닌 `int`로 받는다.
- **개행 문자**: 텍스트 모드에서는 `\n`이 Windows에서 `\r\n`으로 자동 변환되어 저장되고, 읽을 때 다시 `\n`으로 변환된다.
- **인코딩**: 교재의 입출력 함수는 ANSI 인코딩만 처리하므로, 메모장에서 한글 파일을 저장할 때 **ANSI**를 선택해야 한다. (UTF-8이면 글자가 깨짐)
- **fclose의 역할**: 출력 버퍼에 남은 데이터를 실제 파일에 저장하고 자원을 반환한다. 닫지 않으면 데이터가 유실될 수 있다.

## 구현 메모

- 실습과제2·4: 마침표 뒤 공백이 다음 줄 앞에 남지 않도록 줄 맨 앞의 공백은 건너뛰고, 원본에 있는 개행문자는 무시한다.
- 실습과제3: 공백이 포함된 한 줄을 입력받아야 하므로 `scanf("%s")` 대신 `fgets`를 사용한다.
- 모든 실습과제는 `gcc -w`로 컴파일하여 샘플 입력으로 결과를 확인했다.
