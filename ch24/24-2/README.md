## 핵심 개념 정리

- **`fputs` / `fgets`**: `fputs`는 널문자를 저장하지 않으므로 줄을 구분하려면 `\n`을 직접 넣어야 한다. `fgets`는 `(n-1)`개를 읽거나 `\n`을 만나거나 파일 끝에 도달할 때까지 읽고, `\n`도 문자열에 저장한다. 파일 끝이나 오류에서는 `NULL`을 반환한다.
- **`fprintf` / `fscanf`**: `printf`/`scanf`와 사용법이 같고 대상만 화면·키보드에서 파일로 바뀐다. 정수 `10`은 파일에 문자 `'1'`, `'0'`으로 변환되어 저장되고, `fscanf`는 반대로 문자열을 숫자로 변환해 변수에 저장한다.
- **`fscanf`의 반환값**: 정상적으로 읽은 항목 수를 반환하고, 파일 끝이나 오류에서는 `EOF(-1)`를 반환한다. 그래서 `while (1)` 안에서 `ret == EOF`로 반복을 끝낼 수 있다.
- **구분 문자**: `%s`는 공백·탭·줄바꿈 직전까지 읽고 구분 문자는 버퍼에 남긴다. `%c`는 그 구분 문자를 한 글자로 읽어 버리므로 `" %c"`처럼 앞에 공백을 두어야 한다. `%d`는 앞의 공백류를 알아서 건너뛴다.
- **`feof`**: 파일 끝에 도달하면 0이 아닌 값을 반환한다. 입력 함수가 `EOF`/`NULL`을 반환한 이유가 오류인지 파일 끝인지 구분할 때 쓴다. 파일에는 `EOF`가 저장되어 있지 않고, 운영체제가 관리하는 파일 크기로 끝을 판단한다.
- **개행 문자와 인코딩**: 텍스트 모드에서 `\n`은 Windows에서 `\r\n`으로 저장되고 읽을 때 다시 `\n`으로 바뀐다. 교재의 입출력 함수는 ANSI 인코딩만 처리하므로 메모장에서 한글 파일을 저장할 때 **ANSI**를 선택해야 한다.

## 구현 메모

- 실습과제1: 학점이 실수라서 `scanf`는 `%lf`, 파일 출력은 `%.1f`를 사용했다. 한 사람이 한 줄이 되도록 `fprintf` 서식 끝에 `\n`을 넣었다. (슬라이드 예제3의 `fprintf`에는 `\n`이 없어서 한 줄로 이어 저장된다.)
- 실습과제2: `fscanf`가 `EOF`를 반환할 때까지 한 줄씩 읽어 처리하므로 학생 수가 달라져도 동작한다. 평균은 `total / 3.0`으로 계산해 소수점 이하를 유지하고 `%.1f`로 출력한다.
- 실습과제3: 정렬하려면 전체를 먼저 읽어 둬야 하므로 이름·총점·평균을 배열(최대 10명)에 저장한 뒤 총점 내림차순으로 선택 정렬했다. 정렬할 때 세 배열을 함께 교환해야 이름과 점수가 어긋나지 않는다. 동점자는 같은 등수로 묶지 않고 정렬된 순서대로 등수를 매긴다.
- 실습과제2, 3은 `input.txt`를 읽으므로 실행 파일과 같은 폴더에 `input.txt`(ANSI)가 있어야 한다. 파일이 없으면 `파일오픈 실패!`를 출력하고 종료한다.
- 모든 실습과제는 `gcc -w`로 컴파일하여 슬라이드의 예시 입력으로 결과를 확인했다.

## 실습과제4 — 20페이지 예제4-1의 실행 결과 설명

### 문제의 코드

```c
ret = fscanf(fp, "%s%c%d", name, &gender, &age);   // %c 앞에 공백이 없음
```

`friend.txt`에는 `홍길동 M 23`, `임꺽정 M 40`, `장길산 F 30`이 저장되어 있다. 예제4(`"%s %c %d"`)는 정상 동작하지만, 예제4-1은 서식 문자열에서 `%c` 앞뒤의 공백을 뺐기 때문에 결과가 엇갈린다.

### 핵심 원리

1. `%s`는 **공백·탭·줄바꿈 직전까지** 읽고, 구분 문자는 버퍼에 그대로 남긴다.
2. `%c`는 **구분 문자도 한 글자로 읽는다.** (`" %c"`처럼 앞에 공백이 있어야 구분 문자를 건너뛴다.)
3. `%d`는 앞의 공백류를 건너뛰고 숫자를 읽는다. 하지만 숫자가 아닌 문자(`M`, `F`)를 만나면 **읽기에 실패**하고, 그 문자는 버퍼에 남으며 `age`는 **값이 바뀌지 않는다.**
4. 반환값 `ret`는 정상적으로 저장한 항목 수이다. `%d`가 실패하면 2가 되지만 EOF(-1)가 아니므로 반복은 계속된다.
5. `age`는 초기화하지 않아 쓰레기값(`-858993460`, Visual Studio 디버그 모드의 초기값 `0xCCCCCCCC`)이 들어 있다.

### 반복별 추적

(`␣`는 공백, `\n`은 줄바꿈. 파일 내용: `홍길동␣M␣23\n임꺽정␣M␣40\n장길산␣F␣30`)

| 반복 | `%s` | `%c` | `%d` | 반환값 | 출력 |
|---|---|---|---|---|---|
| 1 | `홍길동` (`␣`에서 멈춤) | `␣` (공백을 문자로 읽음) | `M`은 숫자가 아니어서 **실패**, `age`는 쓰레기값 그대로 | 2 | `홍길동 ␣ -858993460` |
| 2 | `M` (남아 있던 `M`을 읽음) | `␣` | `23` (`\n`에서 멈춤) | 3 | `M ␣ 23` |
| 3 | `임꺽정` (앞의 `\n`은 `%s`가 건너뜀) | `␣` | `M`에서 **실패**, `age`는 이전 값 `23` 유지 | 2 | `임꺽정 ␣ 23` |
| 4 | `M` | `␣` | `40` | 3 | `M ␣ 40` |
| 5 | `장길산` | `␣` | `F`에서 **실패**, `age`는 이전 값 `40` 유지 | 2 | `장길산 ␣ 40` |
| 6 | `F` | `␣` | `30` (파일 끝에서 멈춤) | 3 | `F ␣ 30` |
| 7 | 파일 끝 → 입력 실패 | | | EOF(-1) | `break`로 종료 |

그래서 화면에는 이름 줄과 `M`/`F` 줄이 번갈아 출력되고, 성별 자리에는 공백이 들어가 있으며, 나이는 한 칸씩 밀려서 이전 사람의 값이 나온다.

```
홍길동 -858993460
M 23
임꺽정 23
M 40
장길산 40
F 30
```

### 해결 방법

`scanf`처럼 구분 문자를 제거하고 읽어야 한다. 서식 문자열에 공백을 넣어 `%c` 앞의 구분 문자를 건너뛰게 하면 예제4와 같이 정상 동작한다.

```c
ret = fscanf(fp, "%s %c %d", name, &gender, &age);
```

(`gcc`로 같은 데이터를 넣어 위 추적과 동일한 결과가 나오는 것을 확인했다.)
